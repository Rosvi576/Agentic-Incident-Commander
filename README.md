# 🚨 Agentic Incident Commander

An automated Site Reliability Engineering (SRE) copilot designed to perform instant Root Cause Analysis (RCA), engineer code patches, and provide prevention guidelines from raw error logs.

## 🌟 Key Features
- **Instant Root Cause Analysis**: Identifies exact system failure points from unstructured stack traces.
- **Code & Config Remediation**: Automatically generates actionable code patches and configuration fixes.
- **SRE Incident Reports**: Structured, exportable markdown reports for quick team handoffs.
- **Local & Cloud Ready**: Runs locally on Ollama or via Nebius Token Factory for enterprise scalability.

## 🛠️ Tech Stack
- **Frontend / UI**: Streamlit
- **AI / LLM Engine**: Llama 3.2 (via Ollama) / NVIDIA Nemotron (via Nebius Token Factory)
- **Language**: Python 3.11+
